# ThreadShelf Enhanced documentation

ThreadShelf Enhanced is a local AI conversation archive, rich reader, search server, and optional conversation workspace. Import supported exports, organize them into collections, and find useful passages with exact, semantic, or hybrid search. Open complete threads to recover context, then copy or export the material you need.

## Start with an archive

Follow [Quick start](/quick-start/) for a small end-to-end workflow. [Installation](/installation/) covers the source release and project-local runtime on Linux and Windows. [Import conversations](/imports/) explains supported formats, image companions, duplicates, and replacement behavior.

## Add capabilities when needed

The archive works without configuring a generation provider. Optional [local models](/local-models/) or [remote providers](/remote-providers/) support new conversations and continuations. [Markdown notes](/markdown-notes/) connect live note folders. [Text-to-speech](/speech/) adds response playback through installed local voices or selected services.

## Operate and integrate

Review [configuration](/configuration/), [network access](/network-access/), and [backups](/backup-migration/) before moving the archive or exposing it to other clients. Developers can use the [archive HTTP API](/http-api/), [local model API](/model-api/), [MCP](/mcp/), and [command-line tools](/cli/).

## Documentation scope

This handbook describes the Enhanced repository, a distinct fork of ThreadShelf. Installation and capability details are verified against that fork. The upstream documentation remains useful background, but its npm distribution and later upstream changes do not automatically apply here. Guide titles and ordinary setup instructions avoid release-specific names; source references identify the implementation behind each topic.
